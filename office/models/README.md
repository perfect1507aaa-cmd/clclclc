# Модель Алёны Владимировны

Если положить сюда `alena.glb` или `alena.fbx`, игра заменит встроенную модель начальницы на неё:
посадит в кресло, будет поворачивать голову к игроку, подносить трубку к уху и махать рукой.

Подходит любой персонаж с риггингом Mixamo, например:

1. Зайти на https://www.mixamo.com (бесплатный аккаунт Adobe), вкладка **Characters**.
2. Выбрать реалистичную женщину в деловой одежде.
3. **Download** → Format: *FBX Binary (.fbx)*, Pose: *T-pose*.
4. Сохранить файл сюда как `alena.fbx`.

Можно и `.glb` с тем же скелетом (кости `mixamorig:*`). Рост и посадка подбираются автоматически.
