# ПОГРАНПОСТ

Игра в духе *Papers, Please*: вы — инспектор на КПП «Восточный» вымышленной страны Кордония, 1986 год.
Семь смен, с каждым днём правила строже, а вечером нужно платить за жильё, еду и тепло для семьи.

## Запуск

```sh
npm start          # из корня репозитория
# открыть http://localhost:8080/papers/
```

Без зависимостей: чистый HTML/CSS/JS (ES-модули), портреты генерируются процедурно в SVG.

## Как играть

1. **📢 Следующий!** — вызвать въезжающего. Документы появятся на столе, их можно перетаскивать.
2. Сверяйте документы со **Сводом правил** (вкладки: правила, города, печати, районы, розыск).
3. **Цель визита? / Срок?** — ответы должны совпадать с разрешением на въезд.
4. **🔍 Проверка** (Пробел) — выберите два поля (имя в паспорте и в разрешении, лицо в окне и фото,
   дату сверху и срок действия, город и список городов страны, печать и образцы...). Игра подтвердит
   совпадение или покажет несоответствие.
5. Поставьте штамп **РАЗРЕШИТЬ / ОТКАЗАТЬ** и **верните документы**. С 7-го дня — **ЗАДЕРЖАТЬ** разыскиваемых.

5 кредитов за каждого обработанного. Первые 2 ошибки за смену — предупреждение, дальше штраф 5 кр.
Если семья голодает или мёрзнет — заболевает; без лекарств больные умирают. Нечем платить за жильё — конец игры.

Клавиши: `Пробел` — проверка, `Esc` — сброс выбора, `P` — пауза.

Для отладки: `?fast` — смена длится 20 секунд, `?day=N` — новая игра начинается с дня N.

## Структура

- `src/data.js` — страны, имена, правила по дням, газеты, реплики
- `src/generator.js` — генерация въезжающих (валидный комплект + одна «ошибка») и сюжетные персонажи
- `src/rules.js` — проверка нарушений, оценка решения, сравнение полей в режиме проверки
- `src/faces.js` — процедурные портреты и печати (SVG)
- `src/docs.js` — вёрстка документов, `src/desk.js` — перетаскивание по столу
- `src/family.js` — семья и вечерние расходы
- `src/main.js` — игровой цикл, экраны, интерфейс
