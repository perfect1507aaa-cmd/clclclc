# Powerline (клон powerline.io)

Неоновая «змейка» с поворотами под 90°: линия растёт от еды, соперник гибнет,
врезавшись головой в чужую линию, стену или себя, а его тело рассыпается едой.
Главная фишка — **зарядка**: чем ближе голова идёт вдоль чужой линии, тем
сильнее заряд и скорость (искры и дуги у головы).

Запуск (без зависимостей):

```
npm start          # из корня репозитория
# http://localhost:8080/powerline/
```

Управление: стрелки / WASD, свайпы на телефоне или режим «Мышь» в меню;
`1–8` — эмоции, `M` — звук, `Enter` — играть / ещё раз, `Esc` — в меню после смерти.

## Как устроено

| Файл | Что делает |
| --- | --- |
| `src/world.js` | Симуляция: движение, зарядка, коллизии (swept AABB по осевым сегментам), еда, рейтинг |
| `src/snake.js` | Змейка как ломаная: очередь поворотов, минимальный шаг между поворотами, подрезка хвоста |
| `src/grid.js` | Пространственные хэши для сегментов и еды (перестраиваются каждый шаг) |
| `src/brain.js` | ИИ ботов |
| `src/population.js` | Жизненный цикл ботов: заход, жизни, экран смерти, rage-quit, дисконнекты |
| `src/online.js` | Симуляция серверов и онлайна |
| `src/render.js` | Canvas-рендер: точечный фон, неон с blur-свечением, еда, искры, корона, эмоуты |
| `src/main.js`, `src/hud.js` | Меню, HUD, лидерборд, мини-карта, экран смерти |

### Боты

Пять архетипов с разным характером; параметры (скилл, агрессия, жадность, трусость,
осторожность, болтливость, токсичность) случайны внутри архетипа:

- **новичок** — жадный и неуклюжий, поздно замечает угрозы, паникует;
- **казуал** — всего понемногу, бежит на останки, иногда подрезает;
- **пастух (жертва)** — пасётся на пустых полях, бросает еду и удирает от всего, что приближается;
- **киллер** — выбирает жертву (особенно живого игрока), прижимается к её линии, разгоняется
  зарядом, обгоняет и перекрывает путь; убивает больше всех и сам живёт недолго;
- **профи** — эффективно фармит (ищет самые плотные скопления, собирает останки проходом
  вдоль линии трупа), катается на чужих линиях ради скорости, став большим — бережёт массу.

В каждой комнате 4–5 **регуляров** — профи, которые не уходят с сервера, возрождаются за 1–2 с
и снова поднимаются в топ (лидер почти всегда один из них).

Поведение — это намерения с памятью: *пастись*, *пир* (свежие останки притягивают жадных,
жадность снижает осторожность), *охота* (жертва закрепляется на 8–20 с), *бегство* (угрозу
оценивают по размеру, направлению и «преследованию»), *бродить* (к толпе или пастбищу).
У каждого есть любимое пастбище; дрейфующие зоны еды и тяга к толпе собирают игроков в
«тусовки» вместо равномерного разброса.

От скилла зависят реакция (решение исполняется с задержкой), обзор, провалы внимания и
умение видеть ловушки (flood-fill по локальной сетке с учётом уползающего хвоста). Форма
плавает: разогрев в начале, тильт после смертей, уверенность после убийств.

### Онлайн

Регионы (EU, RU, US, SA, Asia) со своим часовым поясом: загрузка идёт по суточной кривой
(пик вечером, провал ночью) плюс медленный шум (процесс Орнштейна–Уленбека). Число комнат
открывается/закрывается под нагрузку. В текущей комнате боты заходят и уходят, чтобы
следовать целевому онлайну; пинг зависит от расстояния до региона и иногда скачет.

### Баланс

`node powerline/tools/headless.mjs 300 [seed] [игроков]` — прогон арены без графики: смерти,
убийства и рост по архетипам, доля времени в каждом намерении, сколько регуляров в топе.
`sh powerline/tools/bench.sh 300 8` — среднее ключевых цифр по нескольким сидам. `node powerline/tools/ascii.mjs pro` — ASCII-снимки
момента смерти ботов выбранного типа с логом их последних решений.
