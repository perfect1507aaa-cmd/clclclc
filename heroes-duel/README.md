# Дуэль героев — сцена (Орден Порядка)

Лоу-поли сцена дуэли в браузере: поле 12×10 клеток, две армии Ордена Порядка
(улучшения против альтернативных улучшений), герои у краёв поля, препятствия.
Пока только сцена — без ходов и боевых механик.

## Запуск

```
node server.js      # из корня репозитория
```

Открыть http://localhost:8080/heroes-duel/ — сборка и зависимости не нужны
(three.js лежит в `vendor/`).

## Управление

- ЛКМ — вращать камеру, ПКМ — сдвигать, колесо — приближение.
- Наведение на отряд — подсказка, клик — карточка существа.
- «Бестиарий» — все 21 существо фракции (7 уровней × базовое / улучшение / альтернатива).
- «Сетка» — показать/скрыть зазоры между клетками, «Камера» — вернуть вид.

## Структура

- `src/data/haven.js` — характеристики существ (атака, защита, урон, HP,
  скорость, инициатива, выстрелы, мана, прирост, стоимость, способности).
- `src/data/abilities.js` — описания способностей.
- `src/data/duel.js` — размер поля, состав и расстановка армий, препятствия.
- `src/scene/models.js` — процедурные лоу-поли модели.
- `src/scene/battlefield.js` — ландшафт, клетки, декор, герои.
- `src/ui/` — панели армий, шкала инициативы, карточка, бестиарий, портреты.

Характеристики альтернативных улучшений стоит сверить с справочником.
