# Дуэль героев (Орден Порядка)

Пошаговая дуэль в браузере в лоу-поли стиле: поле 12×10 клеток, по одному
отряду каждого из 7 уровней Ордена Порядка у каждой стороны.

## Запуск

```
node server.js      # из корня репозитория
```

Открыть http://localhost:8080/heroes-duel/. Сборка не нужна, three.js лежит в `vendor/`.

## Как играть

1. **Расстановка.** Выберите отряд внизу и кликните по клетке в двух своих
   крайних колонках. Отряды одного размера меняются местами. Кнопка под
   отрядом переключает базовый и улучшенный вид. «Против ИИ / 2 игрока» —
   кто управляет красными.
2. **Бой.** Ходы идут по шкале инициативы внизу. Для активного отряда:
   - клик по подсвеченной клетке — перемещение;
   - клик по врагу — атака (с подходом) или выстрел; подсказка показывает урон
     и сколько существ погибнет;
   - «Ждать» (W) — ход сдвигается на середину шкалы;
   - «Защита» (D) — +30% к защите до следующего хода.
   - ПКМ по отряду — карточка существа (на телефоне долгое нажатие).

## Правила, которые уже работают

- Шкала инициативы: ход наступает, когда отряд проходит шкалу; скорость
  продвижения пропорциональна инициативе.
- Перемещение на «скорость» клеток по 8 направлениям (диагональ стоит √2),
  летуны перелетают препятствия, крупные существа занимают 2×2.
- Урон: бросок урона за каждое существо (от 10 существ — пропорционально),
  ×(1 + 5% за каждое очко атаки сверх защиты) или ÷(1 + 5% за очко защиты
  сверх атаки).
- Ответный удар раз за ход (у грифонов — на каждую атаку), на выстрел не отвечают.
- Стрелки: ½ урона дальше 6 клеток и в рукопашной, нельзя стрелять, если враг рядом.
- Большой щит, рыцарский разгон.

Остальные способности (оглушение, залп, точный выстрел, пикирование,
заклинания, лечение, воскрешение) пока не действуют — это отмечено в карточке.

## Структура

- `src/data/` — существа, способности, настройки дуэли.
- `src/game/battle.js` — правила боя, `src/game/ai.js` — противник.
- `src/scene/` — поле, модели, анимации отрядов.
- `src/ui/` — интерфейс.
